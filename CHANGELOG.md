# Changelog

All notable changes to CuteCraft Studio. Format: newest first.

## Unreleased

### Changed

- Bangs now end in sharp points with a slight sweep and uneven lengths, instead of looking like round drops.

### Added

- Portrait view: a button on the preview zooms in on head and shoulders (and back to the full body), so the face is easy to design at anime proportions. The choice is remembered and used for the PNG export.
- First version of the web app: a cute 2D character builder with an anime mode (layered SVG drawing).
- Proportion slider from chibi to anime, plus height, build, shoulders, waist, hips and skin tone.
- Face, eyes, hair, outfit, accessories and background options, all adjustable with live preview.
- Randomize, reset, undo and redo, save to a gallery (kept in the browser), export as PNG.
- German and English interface, switchable in the header; the choice is remembered.
- Web app manifest and app icon, so the page can be added to a home screen.
- The app is published on GitHub Pages and rebuilt automatically after every change to `main`.
